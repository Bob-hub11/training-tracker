TRAINING TRACKER – Installation auf Android

WICHTIG:
Die App speichert Trainingsdaten lokal im Browser auf diesem Gerät.
Lösche nicht die Website-/Browserdaten, wenn du deine Einträge behalten willst.
Nutze in der App regelmäßig „Daten exportieren“, um ein Backup zu sichern.

ECHTE INSTALLATION ALS PWA:
1. Entpacke training-tracker-pwa.zip.
2. Lade den Inhalt in einen HTTPS-Webhosting-Dienst hoch (z. B. GitHub Pages).
   Die Dateien index.html, manifest.webmanifest, sw.js und icon.svg müssen zusammen
   im selben Ordner liegen.
3. Öffne die HTTPS-Adresse auf deinem Android-Handy in Chrome.
4. Tippe auf ⋮ > „App installieren“ oder „Zum Startbildschirm hinzufügen“.
5. Öffne die App über das neue Symbol.

OHNE HOSTING:
Du kannst index.html direkt im Browser öffnen. Die App kann dann als normale
Webseite funktionieren; die Installation als eigenständige PWA ist bei einer
lokalen Datei aber nicht garantiert.

TRAININGS-HINWEIS:
Der Plan ist ein allgemeiner Fitnessplan, kein militärisches Ausbildungsprogramm.
Steigere Belastung langsam, trainiere technisch sauber und vermeide Maximalversuche.
